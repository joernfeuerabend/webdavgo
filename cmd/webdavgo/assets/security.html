Security

Brute-force protection state since the last restart (window {{.Window}}). WebDAV user auth (including /api/v1/), share tokens and the admin login (password, TOTP and recovery codes) share these tables: a lockout from one source blocks the client on all of them. Times are UTC.

Clients

Clients that are locked out or have been before; a repeat lockout lasts twice as long. Unlocking also resets that doubling. "Failures" counts the current window (it restarts with each lockout); "Source" counts all failures since the client was first recorded.

Throttled accounts

Accounts with many failures from any client get at most one password or code check per interval. The real user is slowed down, never locked out. "Remaining" is how long the throttle lasts if no further failures come.

Rate-limited clients

Clients held back by the per-IP connection limit ({{.PerIPLimit}} connections per listener) or the rate limit for WebDAV requests without credentials ({{.UnauthRate}}/s, burst {{.UnauthBurst}}). Both clear themselves within seconds, so there is no manual unlock. A client counts as active while it holds all its connections or has no token left, and for a minute after a refusal.
