# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open public issues or pull requests for security
vulnerabilities.

Report vulnerabilities privately through GitHub Private Vulnerability
Reporting: open the Security tab of this repository and choose
"Report a vulnerability".

If you cannot use GitHub, send your report by e-mail to
security@webdavgo.com.

Include the affected version, a description of the issue and the steps
to reproduce it.
