With tls_mode acme, Save and Apply both run the certificate request with the submitted values: DNS and port 443 checks, a trial order, the real order, then WebDAV moves to HTTPS on port 443 without a restart. The TLS values are written to the config file only once the certificate has been obtained; if the request fails, nothing is saved. Before that, create an A record (and AAAA for IPv6) for the domain and forward external TCP port 443 to this machine. The admin UI needs no forwarding; it is {{.AdminReach}}. tls_mode off is saved at once and takes effect after a service restart.
