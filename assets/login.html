The server prints the token at its first start, as part of the setup URL and on its own "Token:" line. To see it again, run:

Installed service:

sudo webdavgo setup-info

Container:

docker exec <container> webdavgo setup-info
docker logs <container>

setup-info issues a new token if the old one expired. In a container it runs inside the running container, and docker logs shows the output of the first start.
